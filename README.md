# ✦ Altın Saray — Premium Düğün Mekânları

İstanbul'un en prestijli düğün mekânı için hazırlanmış tam kapsamlı web sitesi.

## Özellikler

- 🏛️ **Ana Sayfa** — Hero, istatistik bar, Hakkımızda, 6 salon kartı, Footer
- 📅 **Rezervasyon Sayfası** — Takvim, salon seçimi, zaman dilimi, iletişim formu
- 🌙 **Dark Lüks Tasarım** — `#121212` arka plan + `#D4AF37` altın aksanlar
- 📱 **Tam Mobil Uyum** — Hamburger menü dahil responsive tasarım

## Dosyalar

| Dosya | İçerik |
|-------|--------|
| `index.html` | Ana HTML yapısı |
| `style.css` | Tüm stil tanımları |
| `script.js` | Takvim, form, sayfa geçişleri |

## GitHub Pages ile Yayınlama

1. Repoyu oluştur: `dugun-salonu`
2. Dosyaları yükle
3. **Settings → Pages → Branch: main → / (root) → Save**
4. Site adresi: `https://veysi-lolo.github.io/dugun-salonu/`

## Renk Paleti

| Renk | Hex | Kullanım |
|------|-----|---------|
| Koyu Arka Plan | `#121212` | Ana arka plan |
| Gold | `#D4AF37` | Aksanlar, başlıklar |
